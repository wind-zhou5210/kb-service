# 工作空间（Workspace）需求规范

Version: 1.0
Created: 2026-07-27
Status: Draft

## 1. 概述

### 1.1 背景

产品团队在进行产品设计时，会创建一个项目文件夹，最终产出多层目录的产物：

- BRD / PRD 等 Markdown 文档
- HTML 交互原型（多个页面相互引用，模拟完整网站）
- 图片等静态资源（单独存储在 `assets/` 目录下）
- 不同文档之间的交叉引用（MD 引用图片，HTML 引用图片/CSS/JS）

当前系统的 Collection + Document 模型仅支持扁平化的单文件管理，无法保留文件目录层级、无法处理非文本资源、无法渲染跨文件链接。产品团队需要一种"文件夹即工作空间"的能力，将整个设计产物作为一个整体来管理、预览和分享。

### 1.2 目标

1. 支持整文件夹上传，保持原始目录层级
2. 在浏览器端实现类似本地文件浏览器的预览体验——图片正常显示、跨文件链接无缝跳转
3. 支持生成只读分享链接，团队成员无需登录即可查看完整设计方案

### 1.3 范围

**MVP 范围（P0-P1）**：

| 阶段 | 功能 |
|------|------|
| P0 | 工作空间 CRUD、zip 全量上传、目录树展示、HTML 原生渲染、MD 渲染（含图片路径重写）、内部链接导航 |
| P1 | 分享机制、删除工作空间 |
| P2（后续） | 单文件替换/增量更新、CLI 支持 |

### 1.4 成功指标

- 产品经理可以独立完成"创建→上传→预览→分享"的完整流程
- 上传后 HTML 内的所有图片、CSS、JS 正常加载，无需额外配置
- HTML 页面间的链接点击后跳转到对应页面
- 分享链接发送给其他人后可以直接打开浏览（无需登录）

## 2. 用户分析

### 2.1 目标用户

| 角色 | 使用场景 | 权限 |
|------|----------|------|
| 产品经理 | 上传设计产物、在线预览、生成分享链接 | 全部操作权限 |
| 开发工程师 | 通过分享链接查看设计方案 | 只读（无需登录） |
| 测试工程师 | 通过分享链接了解业务逻辑和交互细节 | 只读（无需登录） |
| 设计师 | 上传交互原型、更新设计资源 | 全部操作权限 |

### 2.2 用户故事

**作为** 产品经理
**我想要** 将本地的设计文件夹（含多层目录和图片）整体上传到工作空间
**以便于** 团队成员在线浏览全部设计产出

**作为** 产品经理
**我想要** 在工作空间中预览 HTML 原型时图片正常显示、链接可以点击跳转
**以便于** 获得与本地浏览器一致的使用体验

**作为** 产品经理
**我想要** 生成一个分享链接发送给开发和测试同学
**以便于** 大家无需登录就能查看完整的设计方案

**作为** 产品经理
**我想要** 在更新设计方案后重新上传覆盖整个工作空间
**以便于** 保持在线展示的内容始终是最新版本

**作为** 开发工程师
**我想要** 通过分享链接查看产品设计的工作空间
**以便于** 理解需求背景和交互细节

### 2.3 用户旅程

**场景：产品经理上传并分享设计产物**

```
1. 登录系统 → 进入工作空间列表页
2. 点击"新建工作空间" → 输入名称和描述
3. 点击"上传" → 选择本地文件夹的 zip 包
4. 系统解压并展示目录树
5. 点击 HTML 文件 → 在浏览器中预览，图片和链接正常工作
6. 点击 MD 文件 → 查看带图片的 Markdown 文档
7. 点击"分享" → 系统生成分享链接
8. 复制链接发送给团队成员
9. 团队成员打开链接 → 查看完整设计方案
```

## 3. 功能需求

### 3.1 核心功能

| 功能点 | 描述 | 优先级 | 验收标准 |
|--------|------|--------|----------|
| 工作空间列表 | 展示所有工作空间，含名称、文件数、总大小、更新时间 | P0 | 列表正确展示，空状态有引导 |
| 创建工作空间 | 创建空白工作空间，输入名称和描述 | P0 | 创建成功后跳转到详情页 |
| zip 上传 | 上传 zip 包，解压后保持目录层级写入磁盘 | P0 | 目录结构完整保留，自动排除隐藏文件和 node_modules |
| 目录树展示 | 左栏展示文件树，区分文档和资源 | P0 | 目录可展开折叠，空目录可见 |
| HTML 渲染 | iframe src= 加载 HTML，支持相对路径解析 | P0 | 图片/CSS/JS 加载正常，链接可点击跳转 |
| MD 渲染 | react-markdown 渲染，图片路径自动重写 | P0 | 本地相对路径的图片正常显示 |
| 内部链接导航 | MD/HTML 文件间点击链接切换到对应文件 | P0 | 点击后切换视图，文件树高亮 |
| 编辑工作空间 | 修改名称和描述 | P1 | 保存后列表和标题更新 |
| 分享链接 | 生成 share_token，只读访问 | P1 | 无需登录，可查看全部文件和内容 |
| 删除工作空间 | 删除并清理磁盘文件和 DB 记录 | P1 | 删除后列表不再显示，磁盘空间释放 |
| 撤销分享 | 使分享链接失效 | P1 | 原链接访问返回 404 |

### 3.2 功能详细说明

#### 功能 1：工作空间 CRUD

- **触发条件**：用户首次使用或管理已有工作空间
- **操作流程**：
  - 列表页：展示所有工作空间卡片，每项显示名称、文件数、更新时间
  - 新建：弹窗输入名称（必填）和描述（选填），提交后进入详情页
  - 编辑：在详情页顶部点击编辑按钮修改名称和描述
  - 删除：二次确认弹窗，确认后删除（⚠ 提示：将同时删除磁盘上的所有文件）
- **业务规则**：删除操作不可逆，需用户二次确认

#### 功能 2：zip 整文件夹上传

- **触发条件**：用户在工作空间详情页点击"上传"
- **操作流程**：
  - 点击上传区域 → 选择本地 .zip 文件
  - 系统后端解压并扫描文件
  - 解压完成后自动展示目录树
- **业务规则**：
  - 自动跳过：`.` 开头的隐藏文件/目录、`node_modules/` 目录
  - 自动跳过：可执行文件（`.exe`, `.bat`, `.sh`, `.dll`, `.so`, `.dmg`, `.msi`）
  - 单文件大小上限 10MB
  - 总 zip 大小上限 500MB
  - 检测到 `../` 等路径遍历攻击 → 拒绝上传并提示错误
  - 重复上传时：全量覆盖，同名文件替换，新文件添加，不存在于新 zip 的旧文件删除

#### 功能 3：文件预览（HTML）

- **触发条件**：用户在目录树中点击一个 .html 文件
- **操作流程**：
  - 右侧预览区以 iframe 加载该 HTML
  - iframe 使用 `sandbox="allow-scripts"` 安全策略
  - 页面内相对路径的图片/CSS/JS 由浏览器自动加载
  - 页面内链接点击后 iframe 内跳转
- **业务规则**：
  - 不做 bleach 净化，安全完全信赖 sandbox
  - iframe 高度自适应（通过 postMessage 上报）
  - iframe 内页面路径变化时通知父窗口，文件树高亮同步

#### 功能 4：文件预览（Markdown）

- **触发条件**：用户在目录树中点击一个 .md 文件
- **操作流程**：
  - 后端返回 MD 原文 + 图片路径已重写为绝对 URL
  - 前端用 react-markdown 渲染
  - 点击内部链接 → 判断目标类型 → 切换到目标文件或新窗口打开
- **业务规则**：
  - 图片重写：`![alt](assets/x.png)` → `![alt](/api/workspaces/{id}/serve/{dir}/assets/x.png)`
  - 外部 URL（http/https）→ 新窗口打开
  - 内部 .md/.html 链接 → 当前页切换视图
  - 其他资源链接 → 直接下载

#### 功能 5：分享

- **触发条件**：用户点击"分享"按钮
- **操作流程**：
  - 生成唯一的 share_token（UUID 格式）
  - 展示可复制的分享链接
  - 团队成员打开链接 → 可查看工作空间的全部文件和内容
- **业务规则**：
  - 分享页面为只读，不展示上传/编辑/删除/分享按钮
  - 可随时撤销分享，撤销后原链接立即失效
  - 重新分享保留原有 token（如有），或生成新的

## 4. 数据需求

### 4.1 数据展示

| 页面 | 展示数据 | 数据来源 |
|------|----------|----------|
| 列表页 | 名称、文件数、总大小、更新时间 | workspace 表 + workspace_file 表统计 |
| 详情页-目录树 | 带层级的文件/目录树 | workspace_file 表，按 path 构建 |
| 详情页-文件内容 | HTML/MD 渲染内容 | 磁盘文件 Serve |
| 分享页 | 同上（只读） | 通过 share_token 关联 workspace |

### 4.2 数据操作

| 操作 | 说明 | 影响范围 |
|------|------|----------|
| 创建 | 插入 workspace 记录 | DB |
| 上传 | 解压 zip → 写磁盘 → 批量插入 workspace_file 记录 | 磁盘 + DB |
| 删除 | 删磁盘目录 → 删 workspace_file 记录 → 删 workspace 记录 | 磁盘 + DB |
| 分享 | 生成/更新 workspace.share_token | DB |
| 撤销分享 | 清空 workspace.share_token | DB |

### 4.3 数据校验规则

| 字段 | 规则 |
|------|------|
| 工作空间名称 | 必填，1-100 字符 |
| 工作空间描述 | 选填，最大 500 字符 |
| 上传文件 | 仅支持 .zip 格式 |
| 单文件大小 | ≤ 10MB |
| 总上传大小 | ≤ 500MB |
| 文件类型 | 非可执行文件白名单 |

## 5. 非功能需求

### 5.1 性能要求

- 500MB 以内 zip 包解压处理时间 ≤ 30 秒（服务器端）
- 目录树加载时间 ≤ 2 秒（10000 个文件以内）
- HTML 页面加载速度与直接打开本地文件基本一致

### 5.2 兼容性要求

- 现代浏览器：Chrome/Firefox/Edge/Safari 最近 2 个主版本
- 桌面端为主，暂无移动端适配要求
- 分享页面同样兼容上述浏览器，无需登录即可访问

### 5.3 安全要求

- 文件上传：zip 解压时逐条检测 `../` 路径遍历，发现即拒绝
- 文件 Serve 认证态：需 JWT 鉴权（iframe 内通过 URL query param 传递）
- 文件 Serve 分享态：通过 share_token 鉴权，路径不可遍历
- HTML 渲染：iframe `sandbox="allow-scripts"`，绝不加 `allow-same-origin`
- 分享 token：UUID 格式，不可猜测
- 隐藏文件自动跳过不存储

## 6. 边缘情况与异常处理

| 场景 | 处理方式 |
|------|----------|
| 上传非 zip 文件 | 前端提示"仅支持 .zip 格式" |
| zip 包损坏 | 返回解压错误提示，保持工作空间原有内容不变 |
| zip 为空 | 前端提示"压缩包中没有有效文件" |
| 单文件超过 10MB | 跳过该文件，继续处理其他文件，在结果中列出被跳过的文件 |
| zip 总量超过 500MB | 上传前拒绝："文件总量超过上限 500MB" |
| 路径遍历攻击 | 检测到 `../` 或绝对路径，拒绝整次上传 |
| 无标题层级（MD） | 不展示目录 TOC，正常渲染内容 |
| HTML 脚本执行错误 | sandbox 已限制，不影响父页面安全 |
| 分享链接已撤销 | 访问时返回 404，提示"链接无效或已失效" |
| 空间不足（磁盘） | 返回 507 Insufficient Storage |
| 并发上传（同一工作空间） | 锁定机制，后一次覆盖前一次 |

## 7. 验收标准

### 7.1 功能验收

- [ ] 可以创建/编辑/删除工作空间
- [ ] 上传一个包含 MD/HTML/图片/CSS/JS 的多层目录 zip，解压后目录结构完整
- [ ] node_modules 和隐藏文件被自动跳过
- [ ] 目录树正确展示层级，可展开折叠
- [ ] 点击 HTML 文件，iframe 内正常渲染，图片显示、CSS 生效、JS 运行
- [ ] HTML 页面间的 `<a>` 链接点击后跳转到目标页面
- [ ] 点击 MD 文件，图片正常显示（相对路径图片已自动重写）
- [ ] MD 内的内部链接点击后切换到目标文件
- [ ] 生成分享链接，在无登录的浏览器中打开可正常浏览全部内容
- [ ] 撤销分享后，原链接访问返回 404
- [ ] 上传恶意路径（包含 `../`）的 zip 被拒绝
- [ ] 删除工作空间后磁盘上的文件也被清理

### 7.2 体验验收

- [ ] 上传时有进度反馈（前端 loading/进度条）
- [ ] 目录树和文件列表加载流畅，无白屏
- [ ] iframe 高度自适应，无滚动条嵌套
- [ ] 分享页面简洁干净，不展示无关操作按钮
- [ ] 错误提示清晰明确，包含处理建议
