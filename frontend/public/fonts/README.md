# 自托管字体（SIL OFL 1.1）

工程图纸·规格单 设计世界的声音，全部自托管，离线可用，无外部运行时依赖。

| 文件 | 字体 | 字重 |
|------|------|------|
| `plexsans-400/500/600.woff2` | IBM Plex Sans | 400 / 500 / 600 |
| `jbmono-400/500/600.woff2` | JetBrains Mono | 400 / 500 / 600 |

- 许可证：**SIL Open Font License 1.1**（允许嵌入与再分发，须保留许可声明）
- 来源：@fontsource 官方构建（https://fontsource.org ），经 jsDelivr 获取的 latin 子集 woff2
  - IBM Plex Sans：https://github.com/IBM/plex
  - JetBrains Mono：https://github.com/JetBrains/JetBrainsMono
- 中文正文使用系统 CJK 字体（PingFang SC / Microsoft YaHei / Noto Sans CJK）回退，拉丁字形与图号/度量由上述字体承载。
